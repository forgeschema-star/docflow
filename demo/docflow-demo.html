DocFlow — Document Converter

A .NET library for converting, reading, and creating Word, PDF, Excel, CSV, HTML, and Image documents. Every service supports file, stream, and byte-array overloads with full async/await support.

.NET 6+ ASP.NET Core DI OpenXML · QuestPDF · ClosedXML Tesseract OCR · PdfPig 6 document types Async throughout

⚙️ Setup & Dependency Injection

Register Services

Defaults only
25 MB limit, system temp dir, logging on
services.AddDocFlowCore();
With custom logger
Plug in your own ILogger implementation
services.AddDocFlowCore(myLogger);
Logger + settings
Full control over all settings
services.AddDocFlowCore(myLogger, settings);
C# — Program.cs / Startup.cs
var settings = new DocFlowSettings
{
    TempDirectory    = "/tmp/docflow",
    OcrDataPath      = "/usr/share/tessdata",
    MaxFileSizeBytes = 50_000_000,   // 50 MB
    LoggingEnabled   = true,
    AllowOverwrite   = false,
};

builder.Services.AddDocFlowCore(logger, settings);

// Injected interfaces available:
// IConversionService, IWordService, IExcelService,
// IPdfService, ICsvService, IHtmlService, IImageService
ℹ️ OCR features (Image → Word / Excel) require the Tesseract data files and a valid OcrDataPath in settings.

🔄 IConversionService

The top-level orchestrator. Routes conversions between format-specific services. Use this when you don't need service-specific extras (templates, OCR, image extraction).

Method Overloads

OverloadInputOutputNotes
Convert(from, to, inputPath, outputPath)file pathfile pathReturns ConversionResult
Convert(from, to, inputStream, outputStream)StreamStreamReturns ConversionResult
Convert(from, to, inputBytes)byte[]—OutputBytes on result
ConvertAsync(from, to, inputPath, outputPath, ct)file pathfile pathAsync
ConvertAsync(from, to, inputStream, outputStream, ct)StreamStreamAsync
ConvertAsync(from, to, inputBytes, ct)byte[]—Async
C# — File-to-File Conversion
var result = await _conversionService.ConvertAsync(
    DocumentType.Word,
    DocumentType.Pdf,
    @"C:\input\report.docx",
    @"C:\output\report.pdf"
);

if (result.Success)
    Console.WriteLine($"Saved to {result.OutputPath}");
else
    Console.WriteLine($"[{result.ErrorCode}] {result.Message}");
C# — Bytes-to-Bytes (ASP.NET Controller)
[HttpPost("convert")]
public async Task<IActionResult> Convert([FromForm] IFormFile file)
{
    byte[] inputBytes;
    using (var ms = new MemoryStream())
    {
        await file.CopyToAsync(ms);
        inputBytes = ms.ToArray();
    }

    var result = await _conversionService.ConvertAsync(
        DocumentType.Word, DocumentType.Pdf, inputBytes
    );

    if (!result.Success) return BadRequest(result.Message);

    return File(result.OutputBytes, "application/pdf", "output.pdf");
}

📄 IWordService

Create a Word Document

C# — Create from plain text
// File-based
await _wordService.CreateWordAsync(@"C:\output\hello.docx", "Hello, World!");

// Stream-based
using var ms = new MemoryStream();
await _wordService.CreateWordAsync(ms, "Hello, World!");

// Bytes — returns byte[]
byte[] docBytes = await _wordService.CreateWordAsync("Hello, World!");

Read a Word Document

C# — Extract text content
string text = await _wordService.ReadWordAsync(@"C:\docs\report.docx");
Console.WriteLine(text);

// Stream overload
string text2 = await _wordService.ReadWordAsync(fileStream);

// Bytes overload
string text3 = await _wordService.ReadWordAsync(docBytes);

Template Placeholder Replacement

ℹ️ Placeholders in the .docx template must be written as {{KeyName}}. Pass an IDictionary<string, string> to replace all occurrences.
C# — Replace {{placeholders}} in a template
var placeholders = new Dictionary<string, string>
{
    { "CustomerName", "Acme Corp"    },
    { "InvoiceDate",  "2024-06-10"   },
    { "TotalAmount",  "$4,500.00"    },
};

// File-based
await _wordService.ReplacePlaceholdersAsync(
    @"C:\templates\invoice_template.docx",
    @"C:\output\invoice_acme.docx",
    placeholders
);

// Bytes — returns modified bytes
byte[] filled = await _wordService.ReplacePlaceholdersAsync(templateBytes, placeholders);

Convert Word → PDF

C#
byte[] pdfBytes = await _wordService.ConvertWordToPdfAsync(docBytes);

// File path overload
await _wordService.ConvertWordToPdfAsync("input.docx", "output.pdf");

All Methods

  • CreateWord / Async — (path, content) · (stream, content) · (content) → bytes
  • ReadWord / Async — (path) · (stream) · (bytes) → string
  • ReplacePlaceholders / Async — (templatePath, outputPath, dict) · (stream×2, dict) · (bytes, dict) → bytes
  • ConvertWordToPdf / Async — (inputPath, outputPath) · (inStream, outStream) · (bytes) → bytes

📕 IPdfService

Read PDF Text

C#
string text = await _pdfService.ReadPdfAsync(@"C:\docs\contract.pdf");
// Returns all text extracted from all pages

Extract Images from PDF

C#
IList<string> savedFiles = await _pdfService.ExtractImagesAsync(
    @"C:\docs\presentation.pdf",
    @"C:\output\images\"      // directory — created if needed
);

foreach (var path in savedFiles)
    Console.WriteLine($"Saved image: {path}");

// Images saved as .png when possible, otherwise .bin

Convert PDF → Word

C#
byte[] wordBytes = await _pdfService.ConvertPdfToWordAsync(pdfBytes);

await _pdfService.ConvertPdfToWordAsync("input.pdf", "output.docx");

Convert PDF → Excel

C#
byte[] xlsxBytes = await _pdfService.ConvertPdfToExcelAsync(pdfBytes);
// Extracts tabular data / lines into an Excel sheet

All Methods

  • ReadPdf / Async — (path) · (stream) · (bytes) → string
  • ExtractImages / Async — (inputPath, outputDirectory) → IList<string> of saved file paths
  • ConvertPdfToWord / Async — (path×2) · (stream×2) · (bytes) → bytes
  • ConvertPdfToExcel / Async — (path×2) · (stream×2) · (bytes) → bytes

📊 IExcelService

Create an Excel File

ℹ️ Data is passed as List<Dictionary<string, string>>. Dictionary keys become bold header columns with a light-gray background on row 1.
C#
var data = new List<Dictionary<string, string>>
{
    new() { { "Name", "Alice" }, { "Role", "Engineer" }, { "Salary", "95000" } },
    new() { { "Name", "Bob"   }, { "Role", "Designer"  }, { "Salary", "88000" } },
};

// File-based
await _excelService.CreateExcelAsync(@"C:\output\team.xlsx", data);

// Bytes
byte[] xlsxBytes = await _excelService.CreateExcelAsync(data);

Read an Excel File

C#
List<Dictionary<string, string>> rows =
    await _excelService.ReadExcelAsync(@"C:\data\employees.xlsx");

// First row is treated as headers (dictionary keys)
foreach (var row in rows)
    Console.WriteLine($"{row["Name"]} — {row["Role"]}");

Template Placeholder Replacement

C# — Replace {{placeholders}} in .xlsx cells
var values = new Dictionary<string, string>
{
    { "ReportMonth", "June 2024" },
    { "Department",  "Engineering" },
};

byte[] filled = await _excelService.ReplacePlaceholdersAsync(templateBytes, values);

Convert Excel → PDF

C#
byte[] pdfBytes = await _excelService.ConvertExcelToPdfAsync(xlsxBytes);

All Methods

  • CreateExcel / Async — (path, data) · (stream, data) · (data) → bytes
  • ReadExcel / Async — (path) · (stream) · (bytes) → List<Dict<string,string>>
  • ReplacePlaceholders / Async — (path×2, dict) · (stream×2, dict) · (bytes, dict) → bytes
  • ConvertExcelToPdf / Async — (path×2) · (stream×2) · (bytes) → bytes

📋 ICsvService

Create a CSV File

C#
var data = new List<Dictionary<string, string>>
{
    new() { { "Product", "Widget A" }, { "Price", "9.99"  }, { "Stock", "42" } },
    new() { { "Product", "Widget B" }, { "Price", "14.99" }, { "Stock", "7"  } },
};

_csvService.CreateCsv(@"C:\output\products.csv", data);

Read a CSV File

C#
List<Dictionary<string, string>> rows =
    _csvService.ReadCsv(@"C:\data\products.csv");

foreach (var row in rows)
    Console.WriteLine($"{row["Product"]}: ${row["Price"]}");

Conversions

C#
// CSV → Excel
await _csvService.ConvertCsvToExcelAsync("products.csv", "products.xlsx");

// Excel → CSV
await _csvService.ConvertExcelToCsvAsync("report.xlsx", "report.csv");

// CSV → PDF (via Excel intermediate)
await _csvService.ConvertCsvToPdfAsync("products.csv", "products.pdf");

All Methods

  • CreateCsv — (path, data) — sync only
  • ReadCsv — (path) → List<Dict<string,string>> — sync only
  • ConvertCsvToExcel / Async — (inputPath, outputPath)
  • ConvertExcelToCsv / Async — (inputPath, outputPath)
  • ConvertCsvToPdf / Async — (inputPath, outputPath) — via Excel

🌐 IHtmlService

Read HTML Text

C#
string text = _htmlService.ReadHtml(@"C:\pages\report.html");
// Returns plain text — all HTML tags stripped

Extract Tables from HTML

C#
List<Dictionary<string, string>> tables =
    _htmlService.ExtractTables(@"C:\pages\data.html");

// First <tr> cells become dictionary keys (headers)
// Falls back to { "Content": rawText } if no <table> elements
foreach (var row in tables)
    Console.WriteLine($"{row["Column1"]} | {row["Column2"]}");

Conversions

C#
// HTML → Word (strips tags, plain text)
await _htmlService.ConvertHtmlToWordAsync("page.html", "page.docx");

// HTML → PDF (via Word intermediate)
await _htmlService.ConvertHtmlToPdfAsync("page.html", "page.pdf");

// HTML → Excel (extracts <table> elements; uses text if none)
await _htmlService.ConvertHtmlToExcelAsync("data.html", "data.xlsx");

All Methods

  • ReadHtml — (path) → string — sync
  • ExtractTables — (path) → List<Dict<string,string>> — sync
  • ConvertHtmlToWord / Async — (inputPath, outputPath)
  • ConvertHtmlToPdf / Async — (inputPath, outputPath) — via Word
  • ConvertHtmlToExcel / Async — (inputPath, outputPath)

🖼 IImageService

⚠️ OCR methods require Tesseract data files and a valid OcrDataPath in DocFlowSettings. English language pack included.

OCR — Extract Text from Image

C#
string ocrText = await _imageService.ReadImageTextAsync(@"C:\scans\invoice.png");
Console.WriteLine(ocrText);
// Uses Tesseract (English). OcrDataPath must be configured.

Conversions

C#
// Image → PDF  (embeds image on A4 page, 20 px margin)
await _imageService.ConvertImageToPdfAsync("photo.jpg", "photo.pdf");

// Image → Word  (OCR text extraction → Word paragraph)
await _imageService.ConvertImageToWordAsync("scan.png", "scan.docx");

// Image → Excel  (OCR text → rows, one line per row)
await _imageService.ConvertImageToExcelAsync("table_screenshot.png", "table.xlsx");

All Methods

  • ReadImageText / Async — (path) → string — OCR via Tesseract
  • ConvertImageToPdf / Async — (inputPath, outputPath) — A4 embed, 20 px margin
  • ConvertImageToWord / Async — (inputPath, outputPath) — OCR → Word
  • ConvertImageToExcel / Async — (inputPath, outputPath) — OCR → rows

⚙️ DocFlowSettings


      

        

          
TempDirectory

          
string

          
Custom temp folder for intermediate files. Auto-created if missing.

          
Default: system temp dir

        

        

          
OcrDataPath

          
string

          
Absolute path to Tesseract language data files. Required for any OCR operation.

          
Default: null (OCR disabled)

        

        

          
MaxFileSizeBytes

          
long

          
Maximum allowed input file size. Files exceeding this return FileTooLarge error code.

          
Default: 25,000,000 (25 MB)

        

        

          
LoggingEnabled

          
bool

          
Enable/disable internal debug, info, warning, and error logging.

          
Default: true

        

        

          
AllowOverwrite

          
bool

          
If false, writing to an existing output path returns OutputAlreadyExists error.

          
Default: false

var defaults = DocFlowSettings.CreateDefault();

// AllowOverwrite = false, TempDirectory = Path.GetTempPath()

📦 ConversionResult

      

        Returned by all IConversionService overloads. Inspect Success first,
        then branch on ErrorCode for recoverable errors.
      


      

        
          
PropertyTypeDescription

        
        
          
Successbooltrue when the conversion completed without errors

          
ErrorCodeConversionErrorCodeReason for failure (None = 0 on success)

          
SourceTypeDocumentTypeInput document type enum value

          
TargetTypeDocumentTypeOutput document type enum value

          
MessagestringHuman-readable success or error message

          
OutputPathstring?Populated for file-path overloads

          
OutputBytesbyte[]?Populated for byte-array overloads

        
      


      

        
C# — Handling all error cases

        
var result = await _conversionService.ConvertAsync(
    DocumentType.Pdf, DocumentType.Excel, inputBytes
);

switch (result.ErrorCode)
{
    case ConversionErrorCode.None:
        return File(result.OutputBytes, "application/vnd.openxmlformats...");

    case ConversionErrorCode.FileTooLarge:
        return BadRequest("File exceeds 25 MB limit.");

    case ConversionErrorCode.OutputAlreadyExists:
        return Conflict("Output file already exists.");

    case ConversionErrorCode.UnsupportedConversion:
        return BadRequest("Conversion not supported.");

    default:
        return StatusCode(500, result.Message);
}
